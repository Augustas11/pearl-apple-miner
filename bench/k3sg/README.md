# k3sg: K3-SG Pearl v3 mining kernel for Apple7–9 GPUs (M1–M4; primary target M3 Ultra) — SPEC §5.3

Design, pattern, mapping and what the Studio must confirm: `docs/kb/k3sg-design.md`.
M5 correctness evidence (correctness only, no perf claims): `bench/evidence/k3sg_m5_correct.txt`.

## Files
| File | What |
|---|---|
| `k3sg.metal` | Kernel, runtime-compiled as Metal 3.1 (no Metal 4/MPP). `-D VARIANT`: `3` production K3-SG (int8 A' m×k / B' k×n row-major → float while staging into threadgroup memory → `simdgroup_matrix<float,8,8>` MMA, fresh fp32 accumulator per 128-wide rank chunk → int32 running accumulator → XOR fold → rotl13 into slot `chunk % 16` → keyed BLAKE3 (key = a_noise_seed) → U256 LE compare vs block and share bounds → bounded `atomic_uint` found slots); `2` fold only; `1` base_f32 (plain fp32 simdgroup_matrix GEMM, same tiling, fp32 operands, C store disabled — the P3 baseline); `0` base_i8 (same, int8 operands). Tiling macros `BM BN BK WM WN PF`. Also `sg_probe` (lane-layout probe) |
| `int8ref.metal` | External reference: the int8bench Metal 4 `matmul2d` kernel (C stored). Dropped with the verbatim error if it does not compile/run on the device |
| `mlx_ref.py` | External reference: MLX `mx.matmul` fp32 in a persistent subprocess, timed in the same paired rounds (wall time) |
| `k3sg.swift` | Host: `probe`, `run JOBDIR [cfgs=..]` (correctness; Swift bit-exact check against `tiles.bin`), `perf`, `sweep`, `sustain` |
| `sg_oracle.py` | `bench/f1_k3/oracle.py` (CPU int64 + blake3 port of zk-pow) with the SG pattern; `tiles.bin` writer |
| `correct_sg.py` | (a)–(e) correctness on 5 jobs × 9 tile cfgs, Python and Swift checks |
| `crosscheck_sg.py` | `pearl_mining` 0.3.1 `mine()` + `verify_plain_proof_for_cert_version(3)` with the SG `MiningConfiguration`, then the same job on the GPU |
| `make_vectors.py` | Pre-generates the Studio oracle vectors (`studio/vectors/`) |
| `build_studio.sh` | Builds the Studio package `studio/` (arm64 binary, minos 14.0, + sources + vectors + `MANIFEST.sha256`) and self-tests it |
| `studio/sg_window.sh` | Studio window runner (≤ 30 min budget; exit 0 pass / 1 step failure / 2 criterion failure) |

Cfg string `BMxBNxBKxWMxWNxPF` (default `64x64x16x2x2x1`); every cfg keeps a 32×32 simdgroup tile, so the Pearl pattern is
the same for all cfgs. Slot layout (26 × u32) and job-dir format are the F1 ones (`bench/f1_k3/README.md`).
Host limits: M % BM = 0, N % BN = 0, K % 128 = 0 (v1 policy r = 128).

## Commands (this Mac)
```bash
cd bench/k3sg   # from the repo root
swiftc -O -target arm64-apple-macos14.0 k3sg.swift -o /tmp/k3sg && cp k3sg.metal int8ref.metal mlx_ref.py /tmp/   # sources next to the binary (or K3SG_SRC_DIR)
/tmp/k3sg probe
K3SG_BIN=/tmp/k3sg K3SG_WORK=/tmp/k3sg_jobs ../../.venv/bin/python correct_sg.py
K3SG_BIN=/tmp/k3sg K3SG_WORK=/tmp/k3sg_jobs ../../.venv/bin/python crosscheck_sg.py
./build_studio.sh                       # package + self-test
# timing on this Mac takes /tmp/pmm-gpu-bench.lock (perf/sweep/sustain do it unless `nolock`)
/tmp/k3sg perf 4096x4096x4096 8192x8192x4096 rounds=31 mlx=$(which python3)
```

## M3 Ultra window
`studio/` is a self-contained package (`./build_studio.sh` builds and self-tests it; the test vectors and binary are
regenerated by `make_vectors.py` and the build, not published). Copy it to the target Mac, then run on an otherwise
idle machine with other GPU workloads paused:
```bash
rsync -a --delete studio/ <target-host>:~/k3sg/
~/k3sg/sg_window.sh       # env overrides: BUDGET_S (1800) ROUNDS (31) SUSTAIN_S (240) CFGS PY
```
Log: `~/pmk-work/logs/sg-<UTC>.log`, per-step outputs in `sg-<UTC>.d/`. All k3sg calls pass `nolock`; the script never
touches launchd, other services, locks or sysctl.

## Perf method (same as F1)
Paired alternating rounds (order reversed on odd rounds), 1 warm-up each, GPU timestamps (MLX: wall incl. dispatch),
identical int8 operands in [−127,127] (base_f32 gets the same values as fp32). P3 ratio per round = t_base_f32 / t_k3;
median and 90% percentile-bootstrap CI. k3 runs with share bound ≈ 4 finds/job, block bound 2^200 − 1, caps 4 / 64.

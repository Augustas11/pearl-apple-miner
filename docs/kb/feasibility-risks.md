# Adversarial feasibility review (Pearl v3 int7 scheme)

Verdicts: **BLOCKER** / **MANAGEABLE** / **MYTH** / **OPEN** (unknown until tested).
The FP8 / cert-v4 successor scheme is analyzed separately in `fp8-cert-v4-risk.md`.

## Summary
- **Only one candidate hard blocker:** R6, whether reading accumulators between K chunks stalls the Neural Accelerator. It must be measured first.
- **Correctness traps:** R7 (default overwrite mode), R18 (large-offset slices), and R19 (consensus rules). Each is fixed by a gate or a test.
- **Real costs, all manageable:**
  - per-job CPU commitment hashing (R10);
  - sustained thermals (R12);
  - OS ≥ 26.4 for int8 tensors (R16).
